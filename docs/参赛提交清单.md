## 四、6 分钟演示脚本

1. **0:00–0:30 问题与创新**：文献调研「看得见引用，看不见为什么」；本作品给出可追溯的语义关系与可追问的星图。
2. **0:30–1:30 建图**：输入种子论文 → 候选确认 → 引文邻域展开 → 星图生长；指出增量构建与节点坐标稳定。
3. **1:30–2:30 关系证据**：点开一条关系，展示原文证据、置信度、可自定义/多标签关系。
4. **2:30–3:30 RAG 问答**：流式回答、角标回原文、比较类问题拆解、证据不足时的补查与停止轨迹。
5. **3:30–4:30 多模态**：上传图表/截图，展示 OCR、表格、数值抽取与区域定位；语音提问或朗读（若已实现）。
6. **4:30–5:30 外部 Agent**：MCP 工具页展示令牌与工具清单，外部 Agent 读取星空并检索原文。
7. **5:30–6:00 工程与安全**：账号隔离、密钥加密、限流与 token 预算、缓存与清理、测试与构建全绿。
